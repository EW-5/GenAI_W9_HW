Research Atlas

**把研究，整理成可以讀懂的筆記。**

Research Atlas 是一個以繁體中文呈現的學術知識整理網站，收錄論文整理、理論筆記與研究方法。透過一致的內容結構，讓讀者快速掌握研究問題、方法、發現與限制，並保留來源及延伸思考。

## 內容與閱讀方式

- **論文整理**：從研究背景、方法、主要發現到貢獻與限制，呈現研究的完整脈絡。
- **理論筆記**：整理核心概念、適用情境與值得進一步思考的問題。
- **研究方法**：說明方法用途、操作步驟與適用條件。

首頁提供文章卡片、主題分類與關鍵字搜尋。點選卡片即可閱讀完整內容，並從文章中的來源說明繼續查閱。

## 內容說明

目前收錄的六篇文章為明確標示的合成 Demo，用於展示網站版型與知識整理方式，不代表真實論文、研究資料或實證成果。

真實研究內容應依原始論文或研究筆記整理，保留來源與閱讀範圍，並區分原文資訊、個人理解及待確認內容。

## 持續擴充的方式

專案以 [AGENTS.md](AGENTS.md) 保存內容格式、命名方式、版型原則與學術誠信規則，作為 AI 協作新增內容的依據。

新增文章時，依既有格式建立一份 JSON，再將文章 ID 加入內容目錄，首頁便會自動顯示新的卡片。論文、理論與方法筆記可使用適合各自內容的章節，同時維持一致的閱讀體驗。

這套規則讓網站能逐篇累積內容，延續相同的整理方式與設計。

## 技術架構

使用 HTML、CSS、JavaScript ES Modules 與 JSON 建立，支援桌面與手機基本版面，可部署於 GitHub Pages。
